# 小麗博士化學實驗室 · Dr. Lily's Chemistry Lab

一個俾 6 至 12 歲小朋友玩嘅 3D 互動化學實驗 Web App。中英雙語，有廣東話（zh-HK）同英式英文（en-GB）朗讀，支援 iPad 觸控。

- 唔使任何構建工具：React 18 + htm、Three.js 0.169、Tailwind，全部經 CDN 載入
- 直接放上 GitHub Pages 就用得
- 打開過一次之後，冇網都玩得（離線版），亦可以「加至主畫面」當 App 咁用
- 29 個實驗（30 個課題）全部有基礎層同「升中挑戰」層
- 有成就徽章同證書、老師專區（交功課、全班進度、今日任務），同埋無障礙設定

## 放上 GitHub Pages

1. Repo 要係 **Public**。免費版 GitHub 唔支援 Private repo 開 Pages。
2. 去 **Settings → Pages**，Source 揀 **Deploy from a branch**，Branch 揀 `main` 同 `/ (root)`，然後撳 **Save**。
3. 等一兩分鐘，就可以用 `https://<用戶名>.github.io/<repo 名>/` 打開。

> ⚠️ 唔好直接雙擊 `index.html`。瀏覽器唔准用 `file://` 載入 JS 模組，會開唔到。
> 想喺自己部電腦測試，可以喺資料夾入面行 `python3 -m http.server 8000`，再打開 `http://localhost:8000`。

> GitHub Pages 只會顯示 `main` 分支。新實驗要 merge 入 `main` 之後，網站先會見到。

## 離線版同「加至主畫面」

- **第一次一定要上網打開一次。**等主頁載入完（大約幾秒），所有實驗同 CDN 檔案就會自動存入部機。之後冇網都可以打開主頁同所有實驗。
- **iPad「加至主畫面」：**用 Safari 打開網站 → 撳分享掣（有向上箭咀嗰個方格）→「加至主畫面」→「加入」。主畫面會多咗個「小麗化學室」圖示，打開就係全螢幕，冇網址列。
- **有網嘅時候會自動攞最新版**；冇網先會用存咗嘅版本。
- 限制：
  - 語音用部機本身嘅語音，離線都讀得；如果部機冇裝廣東話語音，就要先喺「設定 → 輔助使用 → 朗讀內容 → 聲音」下載。
  - 字型（Noto Sans TC）如果第一次打開時未載入完，離線時會用部機自帶嘅中文字型，唔影響使用。
  - 清除 Safari 網站資料，或者長時間冇用，iPad 可能會刪走存咗嘅檔案，到時再上網打開一次就得。
  - 用 `file://` 直接打開唔支援離線版。

## 升中挑戰（第 9 階段）

- 每個實驗做完基礎層，實驗卡會出現「🎓 升中挑戰」掣（未解鎖係 🔒）。
- 升中挑戰沿用同一個 3D 實驗，再加：
  - 正式名詞（中英對照）；
  - 文字方程式，同埋有狀態符號嘅平衡化學方程式；
  - 第一性原理同考試貼士；
  - 3 條題目。
- 想唔使做基礎層都可以直接玩：撳右上角 ⚙️ 設定 → 開「升中模式」；老師亦可以用「今日任務」連結幫全班開。
- 化學式會用香港課堂讀法朗讀，例如 H₂SO₄ 讀「H 二 S O 四」；可以喺設定關。基礎層唔會讀化學式。
- 網址：`…/#/<實驗 id>/challenge`，例如 `…/#/metalrace/challenge`。

## 成就同證書

- 主頁撳「🏅 成就同證書」（`…/#/badges`），可以睇 19 個徽章同進度。得到新徽章會彈出提示。
- 證書：
  - 完成一個主題嘅全部實驗，就有一張主題證書；
  - 完成全部實驗有畢業證書；做晒全部升中挑戰有升中挑戰證書。
  - 證書會印上暱稱同日期，可以列印或者下載 PNG。

## 老師專區同交功課

- **入口**：主頁撳「🧑‍🏫 老師專區」（`…/#/teacher`）。要先答一條乘數題（大人閘）；老師可以設定 4–6 位數字密碼。
- **交功課**：
  1. 學生喺主頁撳「📮 交功課」，寫低暱稱，畫面就會出 QR code；
  2. 老師用 iPad 相機掃 QR code，會打開網站，再過大人閘，就會將學生加入老師部機嘅班表；
  3. 同一個暱稱再交，會更新做最新進度。
  4. 學生亦可以「複製連結」，經 Google Classroom 等平台交俾老師，老師喺老師專區貼上連結就得。
- **全班進度**：表格顯示每位學生完成幾多個實驗、星星、升中挑戰同最後交功課時間，撳「睇詳細」就有逐個實驗嘅記錄。可以「匯出 CSV」（用 Excel 開都睇到中文）或者「列印報告」。
- **今日任務**：剔選今日要做嘅實驗（可以同時開放升中挑戰），就會生成連結同 QR code。學生打開之後，主頁頂部會顯示嗰幾個實驗。
- **私隱**：
  - 冇伺服器、冇帳戶；
  - 進度只會存喺學生部機，同埋（交功課之後）老師部機嘅瀏覽器入面；
  - 請叫學生用暱稱，唔好用全名；
  - 清除 Safari 網站資料會清走記錄。
- **限制**：老師要學生交功課先會見到進度，冇「即時」全班同步。如果將來要即時同步，就要加雲端服務，同時要處理學生私隱同成本。

## 無障礙

- ⚙️ 設定入面可以調：
  - 字體大小（標準／大／特大）；
  - 語速（慢／標準／快）；
  - 高對比；
  - 減少動畫：冇煙花、冇彈跳；如果部機開咗「減少動態效果」，都會自動跟。
- 鍵盤同讀屏：
  - 有「跳到主要內容」連結，同埋清楚嘅 focus 框；
  - 步驟圓點有 `aria-current`，「實驗發現」會自動讀出；
  - 3D 畫面有文字說明。
- 每個動手步驟都可以唔拖放完成：撳「示範俾我睇」或者用工具掣。
- 用 axe-core 自動檢查過主頁、實驗、升中挑戰、成就、證書、交功課、老師專區同設定，冇 serious 或者 critical 問題。

## 點樣加一個新實驗（開發說明）

1. 複製一個最接近嘅模組，例如 `modules/alkali.js`，改名做 `modules/<id>.js`。
2. 喺 `js/modules.js` 加 `import`，再將佢加入 `MODULES`。
3. 喺 `js/syllabus.js` 對應課題加 `modules: ['<id>']`；如果有 `next`，要刪走。下一批課題就加 `next: {zh, en}`，課程地圖會顯示「下一批」。
4. 喺下面「點樣打開實驗」個表加返條網址，再更新路線圖。

### 模組格式

```js
export default {
  id, topics: ['3.2'], accent, dark, bg, theme?,   // 顏色、3D 房間主題
  title: {zh, en}, desc: {zh, en}, Art,            // 主頁卡片
  steps: [{ tag, zh, en, action?: { id, events: ['事件前綴'] } }],
  events: { key: {zh, en} },                       // 3D 場景發出嘅解說
  quiz: { q, options, correct, right, wrong },
  tools: [{ id, label, run: (ctrl) => … }],        // 下面嘅備用按鈕
  Panel,                                           // （選用）記錄表
  build(scene, api) { … return ctrl },             // 3D 場景
};
```

- `tag` 可以係：`intro`、`try`、`observe`、`feynman`、`first`、`life`、`quiz`。
- 有 `action` 嘅步驟：小朋友未做嗰陣，「下一步」會變做「示範俾我睇」。場景做完個動作，要 call `api.done(actionId)`。
- `build` 要 return 嘅 `ctrl`：
  - `cam: { pos, target, fitW }`
  - `demo(actionId)`：Promise，用嚟自動示範
  - `getHint(actionId)`：return `{ from: Vector3, to?: Vector3 }`，提示手指會由 from 去 to
  - `reset()`
  - （選用）`update(dt, t)`、`setStep(i, step)`
- `api` 提供：
  - `api.drag(obj, { label, targets, onDrop, onTap, enabled, lift })`：可以拖嘅物件。`onDrop` return `false` 嘅話，物件會自動返原位。
  - `api.tap(obj, fn, label)`
  - `api.label({zh, en})`
  - `api.emit(eventKey)`
  - `api.state(obj)`：傳資料俾 Panel
  - `api.waitSpeech()`
  - `api.tween`

### 語音規則（重要）

- **換階段要截斷舊語音，即刻讀新內容。**換階段包括：撳下一步、答題，或者發出屬於呢一步 `action.events` 前綴嘅事件。
- **同一階段入面隨意撳物件，唔會打斷老師。**物件嘅解說會排隊，等老師講完先讀。
- **一連串動作嘅解說要逐句讀完。**之間用 `await api.waitSpeech()`，等上一句讀完先觸發下一個事件。

### 升中挑戰格式（`challenge/<id>.js`）

```js
export default {
  steps: [{ tag, zh, en, action?, eq?: [{ word: {zh, en}, sym }], terms?: [{ zh, en }] }],
  events?: { key: {zh, en} },          // 可選：覆蓋基礎層嘅事件解說
  quiz: [{ q, options, correct, right, wrong }, …],   // 3 條
};
```

- `tag` 另外可以用：`term`（正式名詞）、`equation`（化學方程式）、`exam`（考試貼士）。
- `try` 步驟要重用基礎層嘅 `action`，次序同基礎層一樣。
- 化學式一律寫 `[[…]]`，例如 `[[H2SO4]]`、`[[Fe^3+]]`、`[[SO4^2-]]`、`[[e^-]]`、`[[CuSO4.5H2O]]`、`[[Ca(OH)2]]`。
  - 係數寫喺前面，例如 `2[[HCl]](aq)`；狀態符號緊貼喺 `]]` 後面；
  - 方程式要原子同電荷都平衡。
- 加完要喺 `js/challenges.js` import。

### 內容原則

- 基礎層用廣東話口語，生活化，但要保持科學正確；升中挑戰用正式名詞同化學方程式。
- 每個實驗都要跟呢個結構：開場 → 動手試 → 觀察 → 費曼小教室 → 第一性原理 →（生活應用）→ 思考挑戰。
- 有危險嘅地方要加安全提示。
